# 📱 Fe+ — App Católica con Evangelio Diario, Oraciones y Más

**Fe+** es una aplicación móvil católica desarrollada en **Swift** y **SwiftUI** que te acompaña en tu vida espiritual diaria. La app consume una API propia de la Biblia para mostrar el Evangelio del día, oraciones, frases inspiradoras y contenido multimedia.

---

## ✨ Características

- 📖 **Evangelio del día** (integración con API RESTful)
- 🙏 **Oraciones católicas tradicionales**
- 🌟 **Frases y reflexiones de santos**
- 🎧 **Multimedia**: audios, videos y contenido espiritual
- 📅 **Agenda espiritual**: eventos litúrgicos y recordatorios

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Swift 5
- **UI:** SwiftUI
- **Networking:** `URLSession`, `async/await`
- **Persistencia:** Cache in-memory (opcional: UserDefaults, CoreData)
- **Multiplataforma:** Preparada para evolución con Kotlin Multiplatform (KMP)
